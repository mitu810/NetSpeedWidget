# NetSpeedWidget v2.1.1

## 新增功能
- 设置左下角始终显示当前版本与“检查更新”按钮，标题栏同步显示版本。

## 优化改进
- 没有新版本时，在检查按钮旁显示“没有新版本”，不打开弹窗、不跳转页面。
- 有新版本时弹窗显示更新内容和下载按钮；下载进度也在同一个弹窗里显示。
- 下载完成后原按钮直接变成“安装更新”，点击即可安装；稍后安装保留缓存，再次检查无需重复下载。

## 问题修复
- 去掉独立的软件更新页面，纠正此前把更新操作集中在设置页面的交互。
- 下载、安装准备失败在原弹窗展示原因；取消下载和重试不会退出软件。

## 更新说明
- v2.1.0 可通过启动检查或设置中的旧软件更新入口获取此版；v2.0.0 需先退出后手动升级。
- 配置、日志、下载缓存仍在实际 EXE 目录，保持安装版/便携版分别更新，保留配置和失败备份。
- 支持 Windows 10 2004（19041）及以上、Windows 11 x64，发行 EXE 未签名；跨机器安装向导和硬件授权仍需现场验收。

## 下载文件
- 安装版：NetSpeedWidget-v2.1.1-win-x64-Setup.exe。
- 便携版：NetSpeedWidget-v2.1.1-win-x64-Portable.zip。
- SHA256SUMS.txt：用于完整性校验；发行包附带 MIT 和第三方许可证。

## 验证情况
- 原有自动化与更新缓存、校验、回滚、配置保留测试通过。
- 正式包在本机 200% DPI 下验证版本入口：实际点击检查后显示“没有新版本”，没有弹窗。
- 通过弹窗真实下载按钮从 GitHub 下载并校验更新包，弹窗保持打开、进度达到 100%、主按钮切换为“安装更新”；验证模式不执行安装、不修改用户启动项或原运行实例。
- 不同机器的安装向导升级与取消流程尚待现场验收。
