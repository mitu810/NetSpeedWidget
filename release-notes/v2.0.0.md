# NetSpeedWidget v2.0.0

## 新增功能
- 首个公开版本：Windows x64 网速小组件，支持悬浮或任务栏左右显示实时上传、下载速率。
- 可选 CPU/GPU/内存状态与 IPv4/IPv6 双栈网页仪表盘。
- 深浅主题、字体、置顶、位置锁定、当前用户登录自启；独立管理员硬件采集。

## 优化改进
- 多任务栏按窗口句柄独立维护，按目标屏幕 DPI 转换尺寸。
- 原子配置保存、修改字段合并、日志滚动和单实例；快照缓存、有界 HTTP 请求处理及中文密码支持。
- MIT 开源，发行包附带第三方许可及原始版权通知，包含运行依赖。

## 问题修复
- 修复首次授权时任务不存在导致主程序退出的问题。
- 修复首次打开设置窗口与悬浮窗口的 DPI 尺寸裁切。

## 更新说明
- 支持 Windows 10 2004（19041）及以上、Windows 11 x64，无需安装开发工具。
- 此版本尚无应用内更新；升级到 v2.1.0 需先退出旧版并手动安装或解压新版。
- 温度依赖传感器与驱动；标准用户借用另一管理员凭据的授权不支持。HTTP 默认关闭且不提供 TLS；不应暴露到互联网。受保护采集载荷卸载后暂保留。
- 注销登录、新虚拟屏幕、跨 DPI、完整硬件授权及不同机器安装卸载仍需验收。任务栏挂载依赖 Explorer 结构。发行 EXE 未签名。
