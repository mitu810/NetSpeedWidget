# NetSpeedWidget v2.1.3

## 新增功能
- 无。

## 优化改进
- AMD CPU 可读取有效的 Tdie/Tctl 温度传感器；Intel 仍优先读取 Core Average。
- CPU 温度为异常 0 °C 时保持“不可用”，避免显示虚假读数。

## 问题修复
- 修复部分 AMD Ryzen 机器已连接硬件采集进程、传感器也有读数，但仪表盘 CPU 温度仍显示“不可用”的问题。

## 更新说明
- 应用内更新会在当前安装或便携目录替换程序文件，保留配置、日志和缓存。
- 升级后请在“系统状态”中点击“授权/更新采集程序”，确认一次 UAC，以替换旧版管理员采集进程；传感器或驱动确实没有有效读数时仍显示“不可用”。
- 支持 Windows 10 2004（19041）及以上、Windows 11 x64；发行 EXE 未签名。

## 下载文件
- 安装版：NetSpeedWidget-v2.1.3-win-x64-Setup.exe。
- 便携版：NetSpeedWidget-v2.1.3-win-x64-Portable.zip。
- SHA256SUMS.txt：用于完整性校验，发行包附带 MIT 和第三方许可证。

## 验证情况
- 自动化测试覆盖 AMD Tdie/Tctl 优先级、实际传感器名称、0 °C 异常值及原 Intel 行为。
- 本机独立管理员只读检测确认 Ryzen 5 5600GT 的 Core (Tctl/Tdie) 提供有效温度；正式发行包通过构建和隐私检查。
- 用户现有实例升级后的实际仪表盘显示，以及跨机器安装向导流程仍需现场验收。
