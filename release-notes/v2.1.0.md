# NetSpeedWidget v2.1.0

## 新增功能
- 正常启动后台检查稳定版本，也可在设置 → 软件更新手动检查；发现新版本弹窗显示完整更新内容。
- 下载显示进度并可取消；下载完成后可现在安装或稍后安装。重新检查、重启后复用通过校验的缓存，无需重复下载。
- 安装版打开原目录安装向导并显示安装进度；便携版显示独立安装进度，保留配置，完成后重新启动。

## 优化改进
- 下载与安装分开；安装前检查辅助程序准备状态，未准备完成不退出主程序。
- 按数字比较版本，选择本仓库对应发行类型的 x64 附件；校验下载长度、SHA-256 和便携程序版本。
- 配置、日志与应用缓存统一位于实际 EXE 目录；旧安装版配置仅在新位置没有配置时复制迁移，保留原件。
- 统一 Release 六节结构，增加格式验证脚本，安装包版本自动读取主项目版本。

## 问题修复
- 补齐 WinUI 官方控件主题资源，确保更新弹窗与进度控件可在正式单文件包中加载。
- 拒绝缺失或损坏的下载包、ZIP 路径穿越、重复路径、配置覆盖和符号链接目标。
- 便携替换失败尝试从备份恢复旧文件；下载或安装准备失败不结束运行中的软件。

## 更新说明
- v2.0.0 首次升级需手动下载安装 v2.1.0；以后可使用应用内更新。支持 Windows 10 2004（19041）及以上、Windows 11 x64。
- 程序目录必须可写；默认当前用户安装目录满足此要求。更新包与备份位于 EXE 旁 cache/updates，成功确认后可手动清理旧缓存。卸载保留配置与缓存。
- 管理员硬件运行载荷仍放在受保护目录；运行时自身的临时解压由 .NET/Windows 管理。发行 EXE 未签名；SHA-256 用于完整性校验。
- 不自动下载、不自动安装、不切换发行类型；安装向导固定原目录，取消后重新打开原软件。
- 跨机器安装向导、权限受限目录、完整硬件授权、新屏幕及跨 DPI 兼容性仍需现场验收。

## 下载文件
- 安装版：NetSpeedWidget-v2.1.0-win-x64-Setup.exe。
- 便携版：NetSpeedWidget-v2.1.0-win-x64-Portable.zip，解压到固定可写目录后双击 NetSpeedWidget.exe。
- SHA256SUMS.txt：校验下载文件；发行包附带 MIT 和第三方许可证，不含用户配置、日志、缓存或验证记录。

## 验证情况
- 自动化测试覆盖版本比较、发行资产选择、校验失败、取消、缓存复用/损坏重下、ZIP 安全、文件占用回滚、配置保留和迁移；原有测试通过。
- 本机真实 GitHub 稳定版本检查通过；正式自包含主程序、更新辅助程序和安装包构建通过。
- 正式包在本机 200% DPI 下设置/更新页及新版本弹窗检查通过；隔离目录从 v2.0.0 更新至 v2.1.0，配置与旧文件备份保留。
- 不同机器的完整安装与运行兼容性尚未验收，现场边界见更新说明。
